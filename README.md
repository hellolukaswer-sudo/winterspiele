# Winterspiele

Kleine Web-Minispiele fürs Handy. Statische Seite – läuft auf GitHub Pages.

- `index.html`, `css/`, `js/` – die App
- `js/config.js` – Namen, Preise, Trostpreise, Tokens
- `js/games1-4.js` – die 24 Spiele (Schwierigkeit über die Konstanten oben in jedem Spiel)

**Update veröffentlichen:** Versionsnummer in `version.json`, in `index.html` (`APP_VERSION` und alle `?v=`) gleich hochzählen – dann laden alle Handys automatisch neu.
